# CodeRipple Components

A growing collection of **ready-to-use HTML, CSS and JavaScript components** with live previews, clean source code and practical implementation examples.

Built and maintained by [CodeRipple](https://getcoderipple.com/).

## About CodeRipple

CodeRipple is a web development resource focused on reusable frontend components, UI effects and practical tutorials.

Every component is designed to help developers quickly understand, customize and reuse modern frontend patterns in their own projects.

## What You'll Find Here

This repository includes components and examples built with:

- HTML5
- CSS3
- JavaScript
- CSS animations and transitions
- Interactive UI effects
- Responsive frontend patterns

## Component Categories

The CodeRipple component library currently includes:

- CSS Button Effects
- CSS Card Designs
- CSS Text Effects
- CSS Loader Animations
- CSS Navigation Menus
- CSS Background Effects
- CSS Form Designs
- CSS Cursor Effects

More components will be added as the library grows.

## Repository Structure

Components are organized by category, with each component stored in its own folder.

```text
coderipple-components/
├── backgrounds/
├── buttons/
├── cards/
├── cursors/
├── forms/
├── loaders/
├── navigation/
├── text-effects/
├── LICENSE
└── README.md
```

A typical component folder contains:

```text
component-name/
├── index.html
├── style.css
├── README.md
└── script.js
```

> `script.js` is included only when JavaScript is required for the component.

## Using a Component

1. Open the category you want to explore.
2. Choose a component folder.
3. Open `index.html` to view the component structure.
4. Use `style.css` for the component styling.
5. If included, use `script.js` for interactive functionality.
6. Copy, customize and integrate the code into your own project.

Each component is kept separate so you can easily understand and reuse only the code you need.
