# Ripple Click Button

Create a Ripple Click Button using HTML, CSS, and JavaScript. The ripple starts exactly where the user clicks, creating smooth visual feedback with customizable colors and animation speed.

This component is part of the [CodeRipple](https://getcoderipple.com) component library.

## Features

- Clean reusable component structure
- Standalone browser preview
- Easy to customize and reuse
- Interactive JavaScript behavior
- No external libraries required

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

## Files

```text
ripple-click-button/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Usage

Open `index.html` in your browser to preview the component.

Customize the component directly in the HTML, CSS and JavaScript files.
