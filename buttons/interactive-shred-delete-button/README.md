# Interactive Shred Delete Button

A creative **interactive delete button animation** built with HTML, CSS, and JavaScript. When activated, the button creates a shredding-style delete effect that adds visual feedback to destructive actions.

This component is designed for modern web interfaces, dashboards, admin panels, file managers, and other projects where you want to make a delete action more engaging.

## Features

- Interactive shred delete animation
- Smooth CSS transitions and effects
- JavaScript-powered interaction
- Modern dark UI design
- Lightweight and easy to customize
- Built with HTML, CSS, and vanilla JavaScript
- No external framework required

## Technologies Used

- HTML5
- CSS3
- JavaScript
