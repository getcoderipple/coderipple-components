# Product Card

Build a dark Product Card with a rating, current and previous pricing, product badge, description, and Add to Cart button with lightweight CSS hover effects.

Part of the [CodeRipple](https://getcoderipple.com) component library.

## Features

- Standalone reusable component
- Clean HTML and CSS
- No JavaScript required

- `style.css`
