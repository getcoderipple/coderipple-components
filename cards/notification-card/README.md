# Notification Card

Create a Notification Card with a gradient bell icon, unread indicator, message text, timestamp, flexible sizing, and smooth CSS hover effects without JavaScript.

Part of the [CodeRipple](https://getcoderipple.com) component library.

## Features

- Standalone reusable component
- Clean HTML and CSS
- No JavaScript required

- `style.css`

Open `index.html` in a browser to preview the component.
