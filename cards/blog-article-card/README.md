# Blog Article Card

Build a dark Blog Article Card with publication metadata, author information, a gradient visual header, and CSS hover effects for the card and Read More arrow.

Part of the [CodeRipple](https://getcoderipple.com) component library.

- Clean HTML and CSS
- No JavaScript required
