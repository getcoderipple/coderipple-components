# Typing Text Effect

Create a Typing Text Effect using HTML and CSS. The text appears character by character with a blinking cyan cursor, then reverses smoothly for a continuous typewriter-style animation.

## Files

- `index.html` — standalone HTML demo
- `style.css` — component styles

## Usage

Open `index.html` in a browser, or copy the HTML and CSS into your own project.
