# Split Text Hover Effect

Create a Split Text Hover Effect using HTML and CSS. The top and bottom halves move apart on hover to reveal a colorful center layer with a smooth animated transition.

## Files

- `index.html` — standalone HTML demo
- `style.css` — component styles

## Usage

Open `index.html` in a browser, or copy the HTML and CSS into your own project.
