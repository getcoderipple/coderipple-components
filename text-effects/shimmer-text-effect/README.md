# Shimmer Text Effect

Create a Shimmer Text Effect using HTML and CSS. A moving gray, white, and cyan gradient sweeps smoothly across the letters to create a continuous animated highlight.

## Files

- `index.html` — standalone HTML demo
- `style.css` — component styles

## Usage

Open `index.html` in a browser, or copy the HTML and CSS into your own project.
