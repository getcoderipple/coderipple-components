# Glitch Text Effect

Create a Glitch Text Effect using HTML and CSS. Layered cyan and magenta text shifts with clipped sections and quick horizontal movement to create a sharp digital distortion effect.

## Files

- `index.html` — standalone HTML demo
- `style.css` — component styles

## Usage

Open `index.html` in a browser, or copy the HTML and CSS into your own project.
