# Gradient Text Effect

Create a Gradient Text Effect using HTML and CSS. The heading uses animated cyan, purple, and magenta colors that flow smoothly across the text for a clean modern look.

## Files

- `index.html` — standalone HTML demo
- `style.css` — component styles

## Usage

Open `index.html` in a browser, or copy the HTML and CSS into your own project.
