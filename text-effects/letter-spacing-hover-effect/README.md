# Letter Spacing Hover Effect

Create a Letter Spacing Hover Effect using HTML and CSS. The text expands smoothly on hover, changes to cyan, and adds a soft glow for a clean interactive typography effect.

## Files

- `index.html` — standalone HTML demo
- `style.css` — component styles

## Usage

Open `index.html` in a browser, or copy the HTML and CSS into your own project.
