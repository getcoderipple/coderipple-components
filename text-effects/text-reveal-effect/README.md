# Text Reveal Effect

Create a Text Reveal Effect using HTML and CSS. The heading slides smoothly through a hidden container, stays visible briefly, then exits with a clean fading animation.

## Files

- `index.html` — standalone HTML demo
- `style.css` — component styles

## Usage

Open `index.html` in a browser, or copy the HTML and CSS into your own project.
