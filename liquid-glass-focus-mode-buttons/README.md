# Liquid Glass Focus Mode Buttons

A modern set of interactive focus mode buttons featuring a liquid glass-inspired interface, smooth visual transitions and selectable states.

This component is part of the [CodeRipple](https://getcoderipple.com) component library.

## Features

- Liquid glass-inspired button design
- Three interactive focus modes
- Click-based active state switching
- Smooth CSS transitions and visual effects
- Clean HTML, CSS and JavaScript structure
- Easy to customize and reuse
- No external libraries required

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

## Files

```text
liquid-glass-focus-mode-buttons/
├── index.html
├── style.css
├── script.js
└── README.md
```
## Usage

Open `index.html` in your browser to preview the component.

Click any focus mode button to activate its selected state. You can customize the button labels, colors, layout and visual effects directly in the HTML and CSS files.
